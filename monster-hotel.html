《怪物旅馆只剩一间房》隐私政策

Android 包名: dev.local.monsterhotel

更新日期: 2026年10月20日;生效日期: 2026年10月20日。

本游戏由杨磊开发、运营。本政策说明本游戏会处理哪些信息、处理目的、第三方服务及你的选择与权利。隐私与客服联系邮箱: 1073209098@qq.com.

本政策适用于下列游戏各自的 Android 版本。游戏进度与设置在各游戏中分别保存。请结合你正在使用的游戏名称和包名阅读本政策。

核心玩法可离线、免费游玩，不设游戏账号、云存档或游戏内购买。广告是可选服务，拒绝或撤回广告服务授权不会阻止正常游戏。请在了解相关处理后独立选择;阅读本政策、进入游戏或继续游玩不代表你已同意可选广告或个性化广告。

本游戏的数据说明

保存教学和住宿夜次、预约客人、房间设备与布置、服务选择、经营钱包、关系与信件、装饰积分及外观、声音和广告授权设置。用于恢复经营、离店结算和收藏解锁。

一、本地游戏数据

游戏在应用专用存储中保存进度、关卡或经营状态、已解锁内容、外观或装饰积分、声音等设置，用于继续游戏、记住选择和正确结算。各游戏的具体数据见本页的适用游戏说明。开发者没有运营用于接收这些存档的云端账号或存档服务器，本版本不会自动将完整游戏存档上传给开发者。

广告模块另在本机保存一个随机生成的安装标识，以及广告服务授权、个性化偏好、累计游玩时间、每日观看次数、上次展示时间、请求标识、待处理和已领取奖励记录。其用途是记住选择、限制广告频次、恢复中断的结算和防止重复发奖。随机安装标识不取自身份证、手机号, IMEI, OAID 或 Android ID, 也不是你的 TapTap 账号。

本版本不提供通讯录、相册上传、录音、摄像头、聊天、云排行榜或用户生成内容服务，不要求你向游戏提交姓名、身份证、手机号或付款信息。游戏美术和音效为内置资源，运行时不调用生成式 AI 服务。

二、可选广告、联网与个性化选择

只有你在游戏中主动同意可选广告服务，且该选择已成功保存后，游戏才会按当前配置初始化广告 SDK, 并进行广告相关联网。观看激励视频仍需你主动点击;同意广告服务不代表同意自动观看。离线、拒绝授权或广告加载失败时，你仍可完成全部核心玩法。奖励仅增加外观或装饰积分。

你主动请求广告时，游戏会将该游戏广告位、随机安装标识和本次随机请求标识传给 TapADN, 用于加载广告、关联回调和奖励校验。游戏不向广告请求附加你的姓名、身份证、邮箱或完整游戏存档。

启用广告后，游戏还会通过 HTTPS 向 https://www.taptap.cn/ 发出不带游戏存档、随机安装标识或广告奖励记录的 HEAD 请求，读取响应时间，用于每日次数和冷却时间校准。该网络服务会在连接过程中接收到 IP 地址及必要的网络请求信息。拒绝或撤回广告服务后，游戏不再发起新的广告加载与校时请求。

个性化广告默认关闭，与广告服务授权分别选择。你可在游戏设置中的“个性化广告”开关随时更改。关闭后，游戏会通知广告 SDK 退出个性化推荐，仍可能看到非个性化广告;关闭该开关本身不承诺减少广告数量，也不影响游戏进度。

三、第三方 SDK 与外部服务

本 Android 版本使用 TapADN 直连 SDK 5.3.0.4, 提供方为上海艾得蒽数字科技有限公司，用于广告投放、效果统计、奖励验证与反作弊。采集方式包括 SDK 自行采集，以及游戏通过接口传入随机安装标识与本次请求标识. SDK 可能处理：设备品牌、型号、系统版本、屏幕密度与分辨率、语言、时区, CPU 和可用存储容量;应用包名、版本、运行进程及前后台状态;网络类型、信号与 IP 地址;广告展示、点击和转化记录;崩溃与性能信息。关闭入口和具体处理规则见下文及官方政策。

本版本已在 SDK 初始化控制配置中关闭位置、电话状态, Wi-Fi 信息, MAC, SSID/BSSID, 传感器、外部存储, OAID, Android ID 和已安装应用列表等采集入口，并关闭摇一摇。游戏不会向 SDK 主动提供这些信息。此配置不表示广告联网不产生 IP 地址等必要信息;第三方实际处理受 SDK 版本、终端环境及其官方政策约束。

本版本采用 TapADN 直连方式，没有集成穿山甲、优量汇等聚合广告 SDK. Godot 引擎与 OkHttp 网络依赖作为本地程序组成部分使用，本游戏没有为它们配置独立的开发者遥测、云存档或分析服务。

点击广告后，你可能进入广告主、应用商店或外部浏览器。你向该页面主动提交的信息由相应服务按其政策处理，请先阅读该服务的说明。游戏不会自动替你提交联系方式或同意其他服务。

若通过 TapTap 的 TapPlay 免安装环境运行游戏, TapTap 平台会按照其自身政策处理平台账号、实名、防沉迷及运行环境相关信息。本游戏代码没有接收姓名、身份证号或 TapTap 账号资料的接口;本政策不替代平台在使用时向你展示的政策和授权说明。

四、系统权限和设备控制

当前 Android 安装包声明 INTERNET(访问网络)和 ACCESS_NETWORK_STATE(检查网络连接)权限，供你选择启用后的广告及校时服务使用。这类普通网络权限通常不产生系统授权弹窗。你可以通过游戏的广告服务开关控制是否启用这些服务，也可以在设备系统支持的网络管理中关闭本游戏联网。

SDK 合并清单还包含 com.asus.msa.SupplementaryDID.ACCESS 与 freemme.permission.msa 两项部分厂商的设备标识相关权限声明。本游戏已通过 SDK 控制接口禁用 OAID 读取，不会因清单中存在声明就主动打开该采集。

当前包未声明定位、读取电话状态、相机、麦克风、通讯录、短信、外部存储读写、全部应用列表查询或请求安装其他应用等权限。若后续版本新增需要授权的功能，会先说明目的与范围，再按法律及系统规则征求相应授权。拒绝可选权限不会阻止现有核心玩法。

五、保存期限与存储地点

游戏进度、设置和广告奖励账本保存在当前设备的游戏专用存储中，持续到被后续进度覆盖、你清除该游戏数据或删除相应运行环境中的游戏数据。当前 Android 包关闭系统应用数据备份，也不提供开发者云端恢复服务。请在清除、卸载或更换设备前考虑进度丢失风险。

通过 TapPlay 运行时，游戏数据处于平台提供的运行环境中，可能与单独安装的应用数据不共用。请使用平台实际提供的该游戏数据管理或移除功能;删除某一种运行方式的数据不代表其他运行方式的数据也被删除。

广告 SDK 处理的信息由其提供方保存. TapADN 官方政策说明其在中国大陆运营中产生的信息存储于境内，并按提供服务所需期限保留;具体保留、删除和相关权利以该政策及实际处理为准。本游戏开发者未设置向境外传输存档或个人信息的功能。

如果你通过邮箱联系我们，我们会处理你提供的邮箱地址、问题描述及你自愿提供的必要附件，用于沟通和解决请求;仅保留解决问题及履行法定义务所需的信息和期限。请不要发送密码、验证码、私钥或与请求无关的身份证材料。

六、共享、转让与公开披露

除本政策说明的可选广告及联网服务外，开发者不会主动向其他经营者出售游戏存档或你的个人信息。广告服务中的第三方处理按本政策第三节和 SDK 官方政策执行。

如发生运营主体变更、依法需要提供信息或其他新增共享场景，我们将依据适用法律履行相应告知、授权或其他必要程序，并要求接收方依法保护相关信息。未经相应法律依据或授权，不公开披露你的个人信息。

七、查看、更正、撤回与删除

你可在游戏内查看进度、积分和设置，并随时关闭“广告服务”或“个性化广告”。选择成功保存后生效;如界面提示保存失败，请按提示腾出空间或重试。撤回不影响撤回前已依法发生的处理，也不能自动删除 SDK 提供方此前保存的信息。

要删除本机数据，可在 Android 系统的该应用存储管理中清除应用数据，或卸载独立安装的游戏;TapPlay 中请使用平台实际提供的该游戏数据移除方式。该操作会删除相应环境的游戏进度、设置、随机安装标识和广告账本，通常无法恢复。游戏中的“重置关卡”或“开始新轮”仅调整玩法进度，不等于删除全部数据。

本版本没有游戏账号，因此没有账号注销步骤。你仍可请求查询、复制、更正、删除开发者实际持有的信息，或对第三方广告处理提出异议。请发送邮件至 1073209098@qq.com, 注明游戏名称、请求内容和便于回复的方式;如需要，我们仅要求与你的请求相称的身份核验信息。我们将在15个工作日内答复或说明处理进度。

对于 SDK 提供方持有的信息，我们可协助转达请求，或按其官方隐私政策所列渠道联系。我们无法仅凭本地存档恢复你的姓名或第三方设备标识，也不会为了处理请求要求你先开启原已关闭的设备标识采集。法律规定不能立即删除的，将停止超出保存必要范围的处理并依法保护。

八、信息安全

我们采取应用专用存储、存档完整性检查、广告奖励去重、最小化权限和 HTTPS 网络连接等措施，减少意外丢失、错误发奖和未经授权访问的风险。请妥善保管设备，谨慎安装来源不明的软件，不要向他人提供设备调试或存档访问权限。

如发现涉及本游戏的个人信息安全问题，我们会及时核实、采取补救措施，并依据事件影响及法律要求进行通知或报告。你可通过本政策邮箱报告问题。

九、未成年人保护

未成年人应在监护人指导下阅读本政策、合理安排游玩时间。未满14周岁的儿童在涉及个人信息处理或启用可选广告前，应由监护人阅读并作出适当决定;监护人不同意的，请保持广告服务关闭，核心玩法仍可使用。

本游戏没有内购、充值或支付功能，没有为收集儿童身份信息设置专门入口。平台提供的实名和防沉迷由相应平台依其规则实施，不代表本游戏已获取姓名或身份证信息。监护人如认为存在未经适当授权处理儿童信息的情况，请通过邮箱联系我们，我们将核实并依法处理删除等请求。

十、政策更新与联系我们

若处理目的、信息种类、第三方 SDK 或你的权利行使方式发生变化，我们会更新本政策并标明日期;涉及需要重新同意的重大变化，会在相应处理开始前另行提示并征求同意。你可从游戏设置中的隐私政策入口查看当前文本。
